# Microfoundations of AI-Driven Bounded Rationality

An agent-based computational framework investigating how **Reinforcement Learning (RL)**, **Contextual Multi-Armed Bandits (LinUCB)**, and **Large Language Models (LLM)** interact to shape asset price dynamics, market depth, flash crash frequencies, and price efficiency.

> **Note on Outputs:** All empirical results generated by this suite represent synthetic, model-implied market outcomes conditional on specified price-impact and learning rules, rather than direct observations from actual financial markets.

## 📌 Overview

This simulation suite provides a controlled computational laboratory to evaluate multi-agent learning architectures in financial asset markets. It contrasts three distinct market regimes:
1. **`Bandit_Only`**: Market populated exclusively by linear upper confidence bound (LinUCB) contextual bandit agents.
2. **`RL_Only`**: Market populated exclusively by tabular Q-learning reinforcement learning agents.
3. **`Mixed_RL_Bandit`**: Heterogeneous market containing equal proportions of RL and contextual bandit agents.
4. *(Optional)* **`LLM_Only` / `Mixed`**: Markets integrating generative LLM decision agents via Google Gemini API structured outputs.

All agents operate under an endogenous price-impact mechanism driven by aggregate net order demand $D_t$ and a state-dependent market depth proxy $\Lambda_t$.

## 🚀 Key Features

* **Real Macroeconomic Context:** Ingests Federal Reserve Economic Data (FRED) series (`UNRATE`, `CPIAUCSL`, `INDPRO`, `FEDFUNDS`, `GS10`) or custom CSV user inputs.
* **Endogenous Microstructure:** Simulates price formation, order flow imbalances, state-dependent market depth contractions, and flash crashes ($r_t \le -0.05$).
* **Modular LLM Integration:** Periodic querying of Google Gemini models (`gemini-2.5-flash`) using structured JSON action schemas with deterministic fallback rules.
* **Reproducible Execution:** Pre-generated exogenous shock sequences ensuring common random number coupling across scenario comparisons.
* **Publication-Grade Outputs:** Automatic generation of summary CSV files, Monte Carlo Standard Error ($\text{MCSE}$) tables, and vector PDF figures.
